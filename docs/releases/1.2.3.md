# ReLoq C 1.2.3

ReLoq C 1.2.3 moves NVDA add-on updates from GitHub Releases to Forgejo releases. The updater now checks `serrebi/Reloq-C` releases, and each package ships with a published SHA-256 checksum file that the updater verifies before installation. The changes below are relative to 1.2.2.

## Updating

- **New update channel:** **Check for add-on updates** reads Forgejo releases instead of GitHub Releases. Downloads are verified against the published package size and SHA-256 checksum before NVDA's normal installation flow starts.
- **Unchanged:** speech, settings, dictionaries and the synthesis core are identical to 1.2.2.

## Installing

Install this build manually: older builds check GitHub releases and will not find it. The 1.2.3 package retains the NVDA add-on identity used by 1.2.2. It updates existing installations in place and retains settings and dictionaries. This release publishes the NVDA add-on only.
